# Roots Template

Full Roots.io WordPress stack running in Lando — Trellis, Bedrock, Acorn, and Sage
(Laravel Blade + Tailwind CSS theme starter).

## Stack

- **Lando** — local dev environment (Docker orchestration)
- **Trellis** — Ansible-based server provisioning
- **Bedrock** — WordPress boilerplate, Composer-managed
- **Acorn** — Laravel integration layer for WordPress
- **Sage** — Blade + Tailwind starter theme

## Requirements

Docker, Lando, Node.js (LTS), Composer, Git.

## Setup

See `roots-lando-setup.md` for the full build walkthrough, including VPS/Tailscale
networking notes if running Lando remotely.
